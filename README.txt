NovaStar LED Offset — PWA

Pour l'installer comme une application Android :
1. Héberger ce dossier sur un site HTTPS (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Ouvrir l'adresse dans Chrome sur Android.
3. Appuyer sur "Installer l’application" ou Menu ⋮ > Ajouter à l'écran d'accueil / Installer l'application.
4. Après la première ouverture, l'outil fonctionne hors ligne.

Important :
Une PWA ne peut pas être installée normalement depuis un simple fichier local file://.
