Tableau de saisie NovaLCT
Une bande LED correspond à une Receiving Card. La numérotation recommence à 1 pour chaque couple Sending Card / Port et suit le sens d’arrivée RJ45.
Export NovaLCT .scr expérimental. Indique la résolution du média envoyé par le contrôleur ; ouvre le fichier dans NovaLCT avec « Load from File » et vérifie le câblage et les coordonnées avant « Send to HW ».
Schéma Complex Screen
Le schéma reprend automatiquement les zones, les vides et les Start X/Y calculés.
Choisis d’abord la vue depuis laquelle tu as relevé les écrans. Le bouton effectue ensuite la conversion miroir complète.
Configurations enregistrées
Les configurations bêta restent sur cet appareil et sont séparées de la version stable. Utilise l’export JSON pour les sauvegarder.
Formule
Pixels du vide = largeur du montant (mm) ÷ pitch (mm).
Start suivant = Start actuel + résolution LED + pixels du vide.

Actions de la zone

Chaque zone reste modifiable : dimensions, nom et vide après. Aucun vide n’est ajouté entre les morceaux ; le vide existant est conservé après le dernier.
