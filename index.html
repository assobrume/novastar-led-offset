NovaStar LED Offset

Calcul rapide des décalages pour montants de fenêtre / zones vides
Zones LED
Mesure chaque partie LED, puis indique la largeur du montant situé après.
Renseigne les valeurs puis calcule.
Formule
Pixels du vide = largeur du montant (mm) ÷ pitch (mm).
Start suivant = Start actuel + résolution LED + pixels du vide.
